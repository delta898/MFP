## 🌟 BlogGenius로 무엇을 할 수 있나요?

1.  **AI가 대신 쓰는 블로그**: 키워드 하나만 넣어도 사람이 쓴 것 같은 고품질 글이 뚝딱 완성됩니다.
2.  **쇼핑 포스팅 1분 컷**: 상품 링크만 넣으면 알아서 정보를 분석하고 깔끔한 리뷰/홍보글을 써줍니다.
3.  **편리한 글감 관리**: 네이버 트렌드나 RSS 구독으로 보다 편하게 글감을 관리할 수 있습니다. 다 자동이죠.
4.  **잠자는 동안 자동발행**: 설정만 해두면 매일 주기적으로 트렌드를 분석해서 알아서 글을 올려줍니다.
5.  **편리한 네이버 댓글 어시스트**: 내용에 맞는 댓글 후보를 만들어 주어서 보다 편하게 댓글을 달 수 있습니다.
6.  **이제는 텔레그램으로 조작**: 텔레그램을 연결하면 언제 어디에서나 보다 편하게 글을 발행할 수 있습니다.
7.  **핀리한 알림**: 텔레그램이나 Slack 으로 발행 결과를 받아볼 수 있어요. 특히 자동 발행의 경우 매우 편리하죠.
8.  **세련된 디자인**: 보기 편하고 예쁜 화면(GUI)으로 누구나 쉽게 조작할 수 있습니다.
9.  **편리한 셀프 업데이트**: 기능은 무한 발전합니다. 새로운 버전이 있으면 셀프 업데이트를 합니다.

## 🍎 macOS 사용자라면 꼭 확인하세요!

BlogGenius v0.4.3 이상은 **macOS 13(Ventura) 이상**에서 실행할 수 있습니다.

맥(Mac)에서 처음 실행할 때 "확인되지 않은 개발자"라고 뜨나요? 당황하지 마세요!
- 터미널(Terminal)을 열고 프로그램이 있는 폴더에서 아래 명령어를 한 번만 복사해서 붙여넣어 주세요.
  ```bash
  xattr -dr com.apple.quarantine ./BlogGenius.app
  ```
- 이제 마우스 클릭만으로 모든 기능을 즐기실 수 있습니다!
- BlogGenius 를 더블클릭해서 실행해보세요.
