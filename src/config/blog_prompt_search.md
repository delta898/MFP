[검색 중심 제목]
- 제목은 "[메인 키워드] + [구체적인 정보 또는 독자가 얻을 결과]" 흐름으로 구성하세요.
- 메인 키워드는 가능하면 제목 앞부분에 자연스럽게 배치하세요.
- 제목만 읽어도 글에서 다루는 대상과 범위를 알 수 있어야 합니다.
- 숫자, 비교, 결과, 주의점, 궁금증은 본문에 근거가 있을 때만 활용하세요.

[검색 중심 본문]
- 독자가 검색한 질문과 의도에 도입부부터 직접 답하세요.
- 핵심 주제와 키워드를 제목, 도입부, 관련 소제목, 본문과 마무리에 자연스럽게 반영하세요.
- 동일한 키워드를 횟수에 맞추려고 반복하지 말고 문맥에 필요한 만큼만 사용하세요.
- 정의, 이유, 방법, 비교, 주의사항과 결론을 구체적으로 쓰고 대명사보다 명확한 대상을 사용하세요.
- 독자가 필요한 정보를 빠르게 찾을 수 있도록 논리적인 소제목과 정보 구조를 우선하세요.
- 질문-답변 구조는 실제 검색 의도를 명확히 설명하는 데 도움이 될 때만 사용하세요.
- 검색 노출, 순위 또는 성과를 보장하는 표현은 사용하지 마세요.
