[글 작성 전략]
- 전략: 검색 중심
- 목적: 검색 의도와 핵심 정보를 명확하게 전달하는 글

[검색 중심 제목]
- 제목은 "[메인 키워드 또는 대상 식별 단서] + [구체적인 상황] + [본문에서 확인할 이유·결과·판단 중 하나]"의 흐름을 우선하세요.
- 메인 키워드는 가능하면 제목 앞부분에 자연스럽게 배치하세요.
- 제목만 읽어도 글에서 다루는 대상과 범위는 알 수 있어야 하지만, 핵심 이유·결과·비교 결론을 모두 제목에서 소비하지 마세요.
- 검색 질문의 답 전체를 제목에 적기보다 독자가 본문에서 확인할 구체적인 한 가지를 남겨 정직한 호기심 간극을 만드세요.
- 질문형이나 의미적으로 열린 문장은 실제 검색 의도와 연결되고 본문에서 바로 회수할 수 있을 때 활용하세요. 문법적으로 어색하게 끊지 마세요.
- `이것`, `의외의 결과`, `충격`처럼 대상을 알아볼 단서가 없는 상투적 표현만으로 호기심을 만들지 마세요.
- 숫자, 비교, 결과, 주의점, 궁금증은 본문에 근거가 있을 때만 활용하세요.

[검색 중심 본문]
- 독자가 검색한 질문과 의도에 도입부부터 직접 답하세요.
- 제목에서 남겨둔 이유·결과·판단은 도입부에서 방향을 제시하고 관련 본문에서 구체적인 근거와 함께 반드시 회수하세요.
- 핵심 주제와 키워드를 제목, 도입부, 관련 소제목, 본문과 마무리에 자연스럽게 반영하세요.
- 동일한 키워드를 횟수에 맞추려고 반복하지 말고 문맥에 필요한 만큼만 사용하세요.
- 정의, 이유, 방법, 비교, 주의사항과 결론을 구체적으로 쓰고 대명사보다 명확한 대상을 사용하세요.
- 독자가 필요한 정보를 빠르게 찾을 수 있도록 논리적인 소제목과 정보 구조를 우선하세요.
- 질문-답변 구조는 실제 검색 의도를 명확히 설명하는 데 도움이 될 때만 사용하세요.
- 검색 노출, 순위 또는 성과를 보장하는 표현은 사용하지 마세요.

[전략 우선순위]
- 입력 데이터의 Instructions에 이번 글의 구성이나 목적을 바꾸라는 명시적 요청이 있으면 그 요청을 우선하세요.
