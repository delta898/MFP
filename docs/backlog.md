# BlogGenius Backlog

## P1 (다음 스프린트 우선)

1. UI 포트 설정 지원
- `UI_PORT`를 `config/config.txt` 및 UI 실행 인자로 지원
- 기본값 충돌 시 대체 포트 안내/재시도 UX 정리

2. 기본 실행 모드 개선 (Windows 포함)
- `BlogGenius(.exe)` 실행 시 기본 동작을 UI 모드로 시작
- 브라우저 자동 오픈 옵션 제공
- CLI는 서브커맨드(`batch`, `trends`, `shopping`, `license ...`)로 유지

3. 블로그 테이블 텍스트 컬럼 inline edit 고도화
- 현재 inline edit 안정화
- 저장/실패 메시지 미세 조정
- 진행 중(row runtime log 존재) 편집 잠금 유지

4. 실행 로그/최근 실행 표시 UX 정리
- 새 배치 시작 시 이전 runtime 상태 초기화(적용됨)
- 결과 요약 카드 유지 방식(필요 시 이력 탭으로 이전)

5. 블로그 탭 대량 목록 처리
- Trends/Keywords/Topics 공통 페이지네이션 도입 (server limit/offset 연동)
- 현재 단건 조회(limit 확장) 방식에서 페이지 이동 UX(이전/다음/페이지 번호)로 전환
- 매우 많은 행에서도 초기 렌더 지연 없이 동작하도록 최적화

## P2 (중기)

1. 모바일 UI 최적화
- 테이블/액션바 터치 UX 개선
- 화면 폭이 좁을 때 컬럼 축약/카드형 전환 검토

2. 네트워크 바인딩 확장
- 기본 `127.0.0.1` 유지
- 옵션으로 `0.0.0.0` 지원(로컬 네트워크 접근)
- 보안 안내(토큰/방화벽) 문서화

3. 설정 UI (환경설정)
- `config.txt` 전체 노출 대신 “주요 항목”만 입력하는 설정 화면 제공
- 고급 항목은 “고급 설정” 섹션으로 분리
- 저장 시 유효성 검사(필수값/URL/숫자 범위) 적용

4. 네이버 로그인 UX
- UI에서 `로그인 시작` 버튼 제공
- 로그인 진행 상태/완료 상태를 UI에 명확히 표시
- 세션 만료 시 재로그인 유도 메시지 표준화

5. 쇼핑 이미지 소스 입력 UX
- FTC/CTA 이미지를 `https://` URL 뿐 아니라 로컬 파일도 지원
- UI에서 이미지 업로드/선택 후 `config/` 하위에 저장해서 재사용
- 설정값은 URL/로컬 경로 모두 허용(하위 로직에서 자동 판별)

6. UI 팝업 통일
- `alert` 기반 팝업을 앱 내부 모달 컴포넌트로 교체
- 에러/안내/확인 팝업 스타일 및 동작(닫기/확인)을 일관화
- 모바일 화면에서도 가독성/터치 UX가 유지되도록 반응형 적용
- 네이버 로그인 시작 시 현재 차단형 팝업(`alert`) 제거/개선
- 상태 영역 내 비차단 안내(토스트/인라인 배너) 우선 적용 검토

7. 블로그 탭 검색 고도화
- Trends/Keywords/Topics에 공통 검색 UX 통일 (상태 + 자유검색)
- Enter 검색/필터 변경 즉시 반영 동작 표준화
- 검색 조건 유지(탭 이동 후 복귀 시 상태 복원) 적용 검토

8. Trends 날짜 선택 UX 개선
- 현재 텍스트 입력 방식(`YYYYMMDD`, `YYYY-MM-DD`, `-1d`)을 달력 UI 중심으로 개선
- 달력에서 날짜 직접 선택 + `어제` 빠른 선택 제공
- 사용자 확인 팝업 문구와 선택 날짜 표시를 UI/UX 관점에서 일관화
- 기본 기능 안정화 이후(후순위) 적용

9. 쇼핑 빠른발행 미리보기 재도입(재설계)
- 현재는 spec-out 상태 유지(자동 미리보기 호출 제거)
- 재도입 시 자동 blur 트리거 대신 `미리보기` 수동 버튼 방식으로 제한
- 내부 해석은 headless 기반으로만 수행(사용자 브라우저 팝업/포커스 영향 없음)
- 미리보기 실패는 비치명 처리(발행 흐름 차단 금지)
- 결과는 썸네일 중심 카드형(직사각형)으로 간결하게 표시
