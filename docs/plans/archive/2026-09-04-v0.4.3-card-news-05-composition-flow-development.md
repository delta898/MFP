## User Need
Users should be able to use BlogGenius only for the Card News composition and image prompts, create images with another tool when desired, or let the configured image AI complete the same composition. These choices must not become separate, divergent workflows.

## Goal
Make Card News composition the common result and offer two clear entry actions:

- `카드 구성만 만들기`
- `이미지까지 만들기`

Every resulting card exposes its image prompt for review and clipboard copy. Image-slot editing and local file selection remain subsequent stages.

## Scope
- Split composition planning from optional image generation in the Card News domain/service boundary.
- Persist a valid composition even when images are not requested.
- Preserve the existing full image-generation path on top of the shared composition.
- Return image prompts through the public local API without exposing filesystem paths.
- Add two explicit creation actions to the current settings section.
- Show prompt-only cards with an empty image state.
- Let users expand and copy each card's prompt.
- Preserve the last valid result when a later composition or image request fails.
- Keep same/new-style regeneration aligned with the last selected creation path.
- Place the future bulk and per-card AI image controls for visual review without connecting image-fill commands in this stage.

## Explicit Non-goals
- No local image selection, upload, replacement, or workspace copying in this stage.
- No per-card or missing-image AI generation in this stage.
- No publish/readiness gate, SNS integration, Buffer changes, or automation.
- No generated-set history UI or compatibility migration for unreleased internal manifests.

## Design Decisions
- `prompt only` is represented as a composed set whose image slots are empty, not as a separate product mode.
- Both actions call the same composition planner. The image action then fills the resulting slots sequentially.
- Prompt-only completion must not require an image model; it requires only the configured writing model.
- Prompt text remains collapsed by default to keep result cards readable.
- The selected path is carried as explicit generation intent and is not stored as a global application setting.

## Final Result

Each card exposes the exact image prompt for review and copying, empty image slots are explicit, and future bulk/per-card image actions are positioned without being connected prematurely. `구성 다시 만들기` is separated from image regeneration and warns before a successful new composition would clear existing images. The last valid result remains intact on cancellation or failure.
