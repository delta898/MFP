## User Need
The `validate env` workflow fails because `ui/styles/features/dashboard-beta.css` has grown to 906 lines, exceeding the repository's 900-line CSS module boundary.

## Goal
Restore the UI style structure contract without weakening its boundary and without changing Dashboard appearance or responsive behavior.

## Scope
- Move Dashboard Beta responsive rules into a dedicated reachable CSS module.
- Preserve the existing cascade order immediately after the base Dashboard Beta styles.
- Update the explicit CSS manifest contract.
- Run focused structure and Dashboard UI tests.

## Explicit Non-goals
- Do not change visual design or responsive breakpoints.
- Do not raise the 900-line module limit.
- Do not refactor unrelated CSS modules.

## Proposed Design
Keep the core Dashboard Beta styles in `dashboard-beta.css` and move its two trailing media-query blocks into `dashboard-beta-responsive.css`. Include the responsive module directly after the core module in `ui/styles.css`, preserving selector behavior and cascade order while bringing both files comfortably below the structural limit.
