## User Need
After Card News composition is ready, users need to fill image slots without rebuilding copy and prompts. They should be able to use the configured image AI in bulk or per card, and later replace any result with a local image. Existing successful images must survive unrelated failures.

## Goal
Turn the state-based controls introduced in stage 05 into a simple image workspace:

- zero images: create all images or one card image
- partial images: fill all empty slots or create one empty image; existing images remain untouched
- complete set: regenerate all images or one selected image
- any slot: select a local replacement image

## Proposed Scope
- Add provider-neutral service commands for filling all, filling missing, and replacing one card image through the configured image AI.
- Add a safe local-image import command that copies a selected file into the Card News workspace rather than depending on its original path.
- Connect the existing result-level and per-card AI buttons to those commands.
- Add one small per-card local-image action without introducing a separate editor screen.
- Preserve the current composition and every unaffected image when an operation fails.
- Show clear in-progress state and prevent duplicate image operations.
- Recompute the result summary and bulk-button label after each successful change.

## Explicit Non-goals
- No SNS/Buffer publishing, Google Drive archive, automation, generated-set history, or application-side text rendering.
- No crop, filter, canvas, font, or template editor.
- No silent overwrite of unrelated card assets.
- No production or paid-provider calls in automated tests.

## Design Decisions Already Agreed
- Composition and image completion are separate actions after a set exists.
- The exact prompt shown to the user is the prompt used for AI image generation.
- Bulk action depends on slot state: `이미지 모두 만들기`, `빈 이미지 모두 만들기`, or `이미지 모두 다시 만들기`.
- Per-card action is `이미지 만들기` or `이미지 다시 만들기`.
- `구성 다시 만들기` resets images only after confirmation and successful composition replacement.
- The UI remains one continuous workflow; internal project/workspace terminology stays hidden.
