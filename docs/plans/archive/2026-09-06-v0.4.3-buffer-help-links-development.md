# v0.4.3 Buffer Help Links Development Record

## Branch
- Branch: `codex/feature/v0.4.3-buffer-help-links`
- Base/parent branch: `release/v0.4.3`
- Start date: 2026-09-06
- Status: complete

## User Need
Buffer is required when publishing SNS posts from Card News or the SNS composer, but its guidance is currently exposed as isolated external links. Users should be able to find the same Buffer setup guide naturally from Help and from every publishing surface that depends on Buffer.

## Goal
Make Help the single in-app entry point for Buffer guidance, then reuse one compact contextual-help UI from Card News, SNS, and Settings > SNS.

## Scope
- Add the existing Buffer guide to the Help management resources.
- Add or update the configurable Help catalog seed for the same guide.
- Route contextual Buffer help actions through the existing internal Help navigation and guide highlight behavior.
- Show the same compact help action in Card News SNS publishing, the SNS composer, and Settings > SNS.
- Keep the external Buffer signup action separate.
- Add focused shell and browser regression coverage.

## Explicit Non-goals
- Do not change Buffer authentication, channel selection, publishing behavior, or API limits.
- Do not imply that Buffer is required to create or download Card News images.
- Do not deploy or mutate the remote Help catalog in this branch.
- Do not redesign the whole Help or publishing surfaces.

## Proposed Design
The Help view owns one canonical link to the existing Buffer article. Contextual actions call the existing `navigateToHelpGuide` helper with that URL, which opens Help, finds the matching guide, scrolls to it, and briefly highlights it. A small shared contextual-help class provides the same visual language in all three source screens.

The Card News action appears only in the SNS publishing context rather than at the top of the creation workflow. The Buffer signup link remains an external action because it performs a different job from reading setup guidance.

## Affected Boundaries
- Help fallback content and configurable catalog seed
- shared Help navigation
- Card News SNS publishing panel
- manual SNS composer
- Settings > SNS
- shared UI styles and focused contracts

## Decisions and Tradeoffs
- Reuse the existing internal Help navigation instead of creating direct external links in every feature.
- Keep Buffer guidance in the Help management/automation area because Buffer is optional operational setup, not a mandatory first-run step.
- Preserve the signup link as an external secondary action.

## Implementation Stages
1. Establish the canonical Buffer Help resource and catalog entry.
2. Add one reusable contextual Help action and navigation binding.
3. Place it in the three agreed surfaces without widening their layouts.
4. Run focused contract and browser verification.

## Verification Plan

- Verify all three contextual actions target the same guide URL and internal navigation helper.
- Verify the signup link remains external.
