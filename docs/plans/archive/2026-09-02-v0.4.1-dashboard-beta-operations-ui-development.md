# v0.4.1 Dashboard Beta 운영 UI 개발 기록

## Branch

- Branch: `codex/feature/v0.4.1-dashboard-beta-operations-ui`
- Base/parent branch: `codex/feature/v0.4.1-dashboard-upgrade`
- Start date: 2026-09-02
- Status: 완료

## 사용자 필요와 목표

기존 Dashboard를 직접 변경하지 않고 별도의 Dashboard Beta를 만들어 Blog Beta의 현재 운영 상태를 한눈에 확인한다. 사용자가 새 화면을 실제로 비교·검증한 뒤 배포 직전에 기존 Dashboard를 숨기고 새 화면을 정식 Dashboard로 승격할 수 있게 한다.

## 범위

- 기존 Dashboard와 분리된 view, DOM namespace, script, style
- 앱 시작 시 기본 진입하는 `Dashboard Beta` 메뉴와 독립 화면 전환
- 기존 계정 연결·이용 가능 정보의 재사용
- Dashboard Overview API를 이용한 현재 실행 상태
- 연속 발행 활성 상태, 다음 처리 시각, 대기·보관·실행 중 개수
- 다음 발행 글감 최대 3건과 Blog Beta 관련 화면으로 이동하는 행동
- 빈 상태, 로딩, 실패 상태
- focused UI contract 및 관련 browser smoke 검증

## 명시적 비범위

- 기존 Dashboard 제거 또는 hidden 처리
- Dashboard Beta의 정식 이름 전환
- 오늘·이번 주·최근 30일 통계
- 플랫폼별 결과 이벤트와 최근 발행 결과
- 제작자 surface content와 기존 외부 피드 정리
- release, version, push 또는 배포

## 제안 설계

- 기존 Dashboard HTML을 복사하지 않고 Dashboard Beta 전용 partial과 모듈을 만든다.
- 앱 시작 시 Dashboard Beta를 기본 화면으로 열고 계정 Overview와 Blog 운영 Overview를 병렬 조회한다.
- 기존 Dashboard의 데이터와 surface content는 사용자가 기존 화면을 직접 열 때만 조회한다.
- 연결 상태 조회 지연이 Blog 운영 현황 전체를 막지 않도록 두 영역의 상태를 독립적으로 표현한다.
- 운영 정보는 `지금`, `다음`, `대기열`의 순서로 배치하고 세부 설정은 Blog Beta로 이동시킨다.
- 기존 Dashboard의 legacy 자동화 카드와 고정 피드는 가져오지 않는다.
- DOM id와 CSS class는 Dashboard Beta namespace로 격리한다.

## 사용자와 결정한 사항

- Blog Beta 전환 방식처럼 기존 Dashboard를 유지한 채 새 Dashboard Beta를 만든다.
- 사용자 검증이 끝난 뒤 기존 Dashboard는 삭제하지 않고 hidden 처리한다.
- 새 Dashboard는 완료 시 Beta 표기를 제거하고 기본 Dashboard로 승격한다.
- 사용자의 최종 UI 확인 전에는 기존 Dashboard를 변경하지 않는다.
- 기존 Dashboard 구현은 유지하되 앱 시작 화면과 최초 조회 대상은 Dashboard Beta로 한다.

## 구현 단계

1. 기존 shell, 메뉴, view 전환과 Dashboard 데이터 호출 경계 조사
2. 독립 Dashboard Beta shell 및 navigation 추가
3. 연결 상태와 운영 현황 카드 구현
4. 빈 상태·로딩·실패 상태와 이동 행동 구현
5. focused UI contract 및 browser smoke 검증

## 진행 및 변경 기록

- 2026-09-02: Dashboard parent에서 독립 Dashboard Beta 운영 UI sub-feature를 시작했다.
- 2026-09-02: 기존 Dashboard와 분리된 메뉴, view, DOM/CSS namespace, script module을 추가했다. 기존 Dashboard는 기본 화면과 구현을 그대로 유지한다.
- 2026-09-02: 계정 연결 상태와 운영 Overview를 Dashboard Beta 진입 시에만 병렬 조회하며, 응답이 먼저 도착한 영역부터 독립적으로 표시하도록 구성했다.
- 2026-09-02: 현재 발행 흐름, 연속 발행 상태와 다음 시각, 대기·보관·실행 중 개수, 다음 글감 최대 3건을 표시하고 Blog Beta의 글감 관리·연속 발행 설정으로 바로 이동하게 했다.
- 2026-09-02: 실행 중일 때에만 3초 후 재조회하고 화면을 벗어나면 후속 조회하지 않도록 제한했다.
- 2026-09-02: 사용자 피드백에 따라 앱의 기본 active view와 최초 조회 대상을 Dashboard Beta로 변경했다. 기존 Dashboard의 background 조회는 기존 화면을 직접 열었을 때만 수행한다.
- 2026-09-02: 사용자가 실제 화면의 정보 계층과 동작을 확인하고 승인했다.
