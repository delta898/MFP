# v0.4.1 Dashboard 최근 30일 통계·추이 개발 기록

## 사용자 필요와 목표

오늘과 이번 주 활동뿐 아니라 최근 한 달의 작업 흐름을 한눈에 파악한다. `처리 완료`와 `공개 발행`의 최근 30일 누계를 제공하고, 어느 날 활동이 집중되었는지 작은 일별 추이로 보여준다.

## 범위

- 현재 시각을 포함한 최근 30개 한국 날짜의 기간 경계
- 최근 30일 처리 완료·공개 발행 누계
- 날짜별 두 지표의 bounded series
- 기존 Dashboard Beta 기간 선택에 `최근 30일` 추가
- 접근 가능한 간결한 일별 추이 표현과 빈 상태
- focused contract/browser 검증

## 명시적 비범위

- 월간 달력 기준 통계
- 비교 기간 증감률과 예측
- 조회수, 방문자, 검색 순위
- 제작자 콘텐츠와 기존 Dashboard 정리
- release, version, push 또는 배포

## 제안 설계

- `최근 30일`은 달력 월이 아니라 오늘을 포함한 연속 30개 날짜다.
- 누계는 기존 플랫폼 성공 이벤트 계약을 그대로 사용한다.
- 추이는 30개의 날짜 bucket을 항상 반환해 활동이 없는 날도 0으로 표현한다.
- 복잡한 차트 라이브러리 없이 처리 완료량을 막대, 공개 발행량을 그 안의 강조 막대로 표시한다.
- 색상만으로 의미를 전달하지 않고 범례와 날짜별 접근성 설명을 제공한다.

## 사용자와 결정한 사항

- 최종 기간 선택은 오늘, 이번 주, 최근 30일까지 제공한다.
- `처리 완료`와 `공개 발행` 구분은 모든 기간에서 동일하게 유지한다.

## 구현 단계

1. 최근 30일 기간과 날짜 bucket projection
2. API allowlist 확장
3. Dashboard Beta 기간 선택·추이 UI
4. focused contract와 browser smoke 검증
5. 사용자 UI 확인 후 완료 기록 및 parent merge 준비
