# Keyword Discovery Modal Plan

## Goal

빠른 포스팅에서 사용자가 새 글의 출발점을 직접 고를 수 있는 `새 글 시작` 모달을
제공한다. 글감과 키워드는 서로 다른 필요를 해결하지만 하나의 시작 흐름으로 보인다.

## Product Boundary

- `글감 추천`: 개인의 관심사, 최근 활동과 트렌드 신호를 프로그램적으로 후보화하고,
  AI는 선택된 후보를 글감 문구와 추천 근거로 정리한다. 사용자의 명시적 실행에서만 AI를 호출한다.
  선택 입력인 `글감 힌트`는 현재 주제·키워드 의도를 전달하며, GraphDB에서 조회한 관심 주제와
  최근 글쓰기 artifact의 일치 신호를 후보화에 우선 반영한다.
- `키워드 탐색`: AI를 사용하지 않는다. 최신 트렌드, 개인 관심사/최근 활동에서 raw seed를
  모으고 Naver Search Ads와 최근 7일 블로그 문서 지표를 보여준다. 자동 추천, 자동 체크,
  의미 적합성 필터는 두지 않는다.
- `키워드 검색`: 사용자가 직접 입력한 1~3개 키워드를 raw seed로 사용한다. 탐색 후보를
  섞지 않고 해당 키워드와 연관 검색어의 지표를 보여준다.
- `트렌드 포스팅`: 트렌드 기반 발행 작업 흐름으로 유지한다. 키워드 탐색은 발행하지 않고
  새 글의 키워드를 사용자가 고르는 탐색 표면이다.

## UX Flow

```text
빠른 포스팅 > 바로 생성
  -> Subject 옆 글감 추천 > 글감 추천 탭 > 선택 힌트 입력 > 명시적 AI 실행 > 글감 선택
     -> 주제/키워드/지시사항 채움, 제목 비움 > 빠른 포스팅
  -> Keywords 옆 키워드 탐색 > 키워드 탐색 탭 > 명시적 Naver 데이터 조회 > 1~3개 키워드 선택
     -> 첫 키워드는 주제로, 전체 키워드는 쉼표 목록으로 채움, 제목 비움 > 빠른 포스팅
  -> 키워드 검색 > 직접 입력 seed와 연관 검색어 지표 > 재탐색 또는 키워드 선택
```

모달을 여는 것만으로는 외부 API나 AI를 호출하지 않는다.
Keywords 입력란에서 모달을 열면 현재 입력값을 시작 키워드로 복사한다. 사용자는 이를
확인하거나 수정한 뒤 명시적으로 `키워드 탐색`을 실행한다.

글감 힌트가 있으면 그 입력값은 첫 후보로 보장한다. GraphDB에서 읽어 온 owner profile
키워드와 최근 작성 artifact 중 문자열 일치 신호를 우선 후보화하고, 일치 신호가 없을 때만
기존의 넓은 관심사·활동 풀로 보완한다. 이 과정은 의미를 단정하는 자동 필터가 아니라
후보 검색 범위 조정이며, 최종 후보 선택은 프로그램 로직, 문구화는 AI가 맡는다.

## Data Contract

새 키워드 탐색 서비스는 최대 세 개의 raw seed를 source-balanced하게 수집한다.

1. Naver Trends 최신 신호
2. GraphDB/owner profile 관심 키워드
3. 최근 글쓰기 또는 활동 키워드

각 seed는 출처를 보존한 채 기존 `keyword-research` 서비스로 전달한다. 이 서비스는
Search Ads 관측값과 최근 7일 신규 블로그 문서를 수집하고, 입력 seed와 연관 후보를
지표로 반환한다. 연관 후보는 의미 판단 없이 중복과 seed만 제외한다.

탐색을 다시 실행할 때는 직전 seed를 우선 제외하고 각 source pool에서 무작위로 새 seed를
고른다. 다른 후보가 충분하지 않은 경우에만 기존 seed를 다시 사용할 수 있다.

## Implementation Steps

1. `keyword-discovery` UI API service, controller, route와 단위 테스트를 추가한다.
2. `새 글 시작` 모달과 글감/키워드 탭을 추가하고 기존 글감 목록 렌더러를 옮긴다.
3. 키워드 지표 표와 선택 적용을 구현한다.
4. 추천 결과/기존 입력/preview를 교체하는 초안 초기화 경로를 공통화한다.
5. API 및 UI 회귀 테스트를 실행한다.

## Non-goals

- 키워드 탐색 결과의 자동 대표 키워드 선정
- 사용자 동의 없는 AI 호출
- 트렌드 포스팅의 발행 흐름 변경
