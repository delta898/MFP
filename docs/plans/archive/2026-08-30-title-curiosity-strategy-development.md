## 사용자 필요

현재 검색 중심 제목은 정보 전달에 충실하지만 제목만으로 본문 내용을 모두 예상하게 만들 수 있고,
발견 중심 제목도 낚시 방지에 치우쳐 독자가 다음 내용을 확인할 이유를 충분히 만들지 못할 수 있다.
검색과 피드 모두에서 사실성을 지키면서 클릭과 유입을 높일 수 있는 제목 전략이 필요하다.

## 목표

- 검색·발견 전략 모두에 `정직한 호기심 간극`을 적용한다.
- 제목에는 대상과 효용을 식별할 단서를 남기되 이유·결과·판단을 전부 소비하지 않는다.
- 제목에서 만든 열린 고리를 도입부 또는 본문에서 반드시 회수하게 한다.
- 상투적인 `이것`, 과장, 허위 경험·수치, 본문과 무관한 미완성 문장은 제한한다.
- 전략별 차이는 유지한다: 검색은 검색 의도와 식별 가능성, 발견은 상황과 읽기 흐름을 더 강하게 둔다.

## 범위

- 블로그 검색 중심·발견 중심 전략 프롬프트
- 전략 선택 및 프롬프트 계약 테스트
- 빠른 글 작성의 AI 제목 추천 및 키워드 분석 후 제목 추천 경로
- 관련 개발 문서와 backlog 현행화

## 명시적 비목표

- 클릭률이나 유입 성과 보장
- 실제 검색·피드 노출 알고리즘 변경
- 제목 A/B 테스트나 성과 측정 기능
- AI 모델 또는 글쓰기 프로필 UI 변경

## 설계와 결정사항

1. 호기심은 `정보 은폐`가 아니라 `제목에서 결론을 전부 소비하지 않는 것`으로 정의한다.
2. 검색 중심은 메인 키워드와 대상 식별 단서를 유지하면서 이유·결과·비교 결론 중 하나를 남긴다.
3. 발견 중심은 상황·변화·의외성·공감 문제를 먼저 보여주고 다음 문장을 읽을 의미적 열린 고리를 만든다.
4. 문법적으로 억지로 끊거나 따옴표 속 `이것`만 반복하는 상투적 제목은 금지한다.
5. 제목의 약속과 궁금증은 본문에서 구체적으로 회수하며, 입력 자료에 없는 경험·수치·갈등은 만들지 않는다.

## 구현 단계

1. 기존 전략 프롬프트와 계약 테스트 확인
2. 검색·발견 제목 및 본문 회수 규칙 보완
3. 전략별 계약 테스트와 문서 현행화
4. 집중 테스트와 전체 회귀 검증

## 진행 기록

- `dev`에서 feature 브랜치를 생성했다.
- 기존 프롬프트가 검색 중심의 명확성 및 발견 중심의 낚시 방지는 다루지만,
  두 전략 모두에 적용할 적극적인 호기심 간극 규칙은 부족함을 확인했다.
- 검색 중심에는 대상 식별과 검색 의도를 유지하면서 이유·결과·판단 중 하나를 본문에 남기는 규칙을 추가했다.
- 발견 중심에는 구체적인 상황 단서를 공개하면서 다음 내용을 확인해야 의미가 완성되는 열린 고리 규칙을 추가했다.
- 두 전략 모두 상투적인 `이것` 남용, 어색한 문장 절단, 근거 없는 경험·수치와 본문 미회수를 금지했다.
- 별도 제목 추천기가 본문 생성 프롬프트를 공유하지 않는 경로임을 추가 확인했다.
- 빠른 글 작성의 두 제목 추천 진입점이 동일 제목 생성기를 사용하며, 선택한 검색·발견 전략을 `title_mode`로 전달하도록 연결했다.
- 제목 전용 프롬프트에도 검색·발견·균형 모드별 정직한 호기심 간극과 본문 회수 계약을 적용했다.

## 결과 및 검증

- 검색·발견 전략 모두 제목에서 핵심 결론을 전부 소비하지 않고 본문으로 이어지는 정직한 호기심 간극을 사용한다.
- 검색 중심은 키워드와 대상 식별성을, 발견 중심은 상황과 읽기 흐름을 우선하는 기존 차이를 유지한다.
- 두 전략 모두 제목의 열린 고리를 본문에서 반드시 회수하고 근거 없는 과장과 상투적인 정보 은폐를 제한한다.
- 최종 집중 프롬프트·제목 추천·generation·preview·UI 연결 테스트 35개 통과
- 최종 전체 unit regression 1,134개 통과
- 첫 전체 회귀에서 병렬 실행 부하로 MCP process restart 테스트 1건이 일시적으로 timeout 되었으나,
  해당 파일 단독 3개 및 이후 전체 회귀 재실행이 모두 통과했다.

## 남은 위험과 후속 작업

- 클릭 가능성은 높일 수 있어도 실제 성과는 제목·본문 적합성, 독자, 플랫폼 노출 신호에 따라 달라진다.
- 향후 제목 후보 비교 및 실제 성과 학습은 별도 기능으로 다룬다.
