## User Need
The shared clock and timer control menu is clipped at the bottom edge of the Dashboard header card. The behavior occurs on every supported OS when the control is opened from Dashboard Beta.

## Goal
Allow the complete clock and timer menu to extend below the Dashboard header while preserving the existing position, styling, and behavior on all other screens.

## Scope
- Remove the Dashboard Beta hero's clipping boundary.
- Keep the shared clock menu layout and anchor unchanged.
- Add a focused Dashboard UI contract to prevent the clipping rule from returning.
- Update release-facing notes and the parent release record.

## Explicit Non-goals
- Do not redesign the clock or timer controls.
- Do not change menu placement on other screens.
- Do not change responsive layout beyond allowing the menu to remain visible.

## Design and Decision
The menu is absolutely positioned below `.clock-widget-unit`. Dashboard Beta alone wrapped it in `.dashboard-beta-hero` with `overflow: hidden`, so the parent card clipped the menu at its lower boundary. The hero background and border radius do not require child clipping, so changing that boundary to `overflow: visible` is the smallest sufficient fix.
