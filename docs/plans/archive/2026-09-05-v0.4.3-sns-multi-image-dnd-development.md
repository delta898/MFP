# v0.4.3 SNS Multi-Image Drag and Drop

## Branch

- Branch: `codex/feat/v0.4.3-sns-multi-image-dnd`

- Start date: 2026-09-05
- Status: complete; user approved parent integration

## User Need

The new square image grid should support the familiar action of dropping local files directly into it. Users also need the visible order to match the intended SNS carousel order.

## Goal

Add file drag-and-drop and simple image reordering to the existing local preview grid without changing Google Drive or Buffer publishing contracts.

## Scope

- Accept supported local image files dropped onto the image grid.
- Show a clear drag-over state.
- Allow selected image tiles to be reordered by dragging.
- Keep sequence numbers synchronized with the resulting order.
- Preserve file-picker addition and per-image removal.
- Add focused browser coverage for the stable interaction contract where practical.

## Explicit Non-goals

- Google Drive multi-file upload.
- Buffer multi-image publishing.
- Touch-specific gesture sorting or a third-party sorting dependency.
- Live SNS publication.

## Proposed Design

Use native browser drag events. The containing grid handles external file drops, while each tile carries its current index for internal reordering. State remains the existing ordered local-image array, so the next transport stage can consume the same deterministic order.

## Verification Plan

- Syntax and focused SNS service tests.
- Browser smoke for the composer initialization contract.
- Manual confirmation of drag-over styling, file drops, reordering, and sequence updates.
