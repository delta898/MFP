## 사용자 필요와 목표

원고 생성이 오래 걸리면 사용자가 취소하고 모델을 바꿔 재시도할 수 있어야 한다. 취소 확인 전에는 중복 실행을 막고, 기존 유효 원고와 입력은 유지한다.

## 범위와 비범위

- `블로그 Beta`의 AI 원고 생성 버튼 옆 취소 동작과 진행 상태 패널.
- 비동기 시작·상태 조회·취소 API 연결, 탭 복귀 시 현재 작업 복원, 늦은 응답 무시.
- 관련 UI 계약 테스트와 브라우저 smoke.
- 기존 블로그 화면, 발행·개별 이미지 작업 취소는 비범위.

## 설계와 결정

기존 생성 버튼·상태 패널을 재사용한다. 생성 중 보조 `생성 취소` 버튼을 보이고, 취소 요청 후에는 `취소 요청 중…`으로 바꾼다. 서버가 종료를 확인할 때까지 재실행을 막는다. 완료 시에만 새 Draft를 반영하며 실패·취소에는 마지막 유효 미리보기를 유지한다. KIE 작업 중에는 로컬 중단이 원격 과금 취소를 의미하지 않는다는 짧은 안내를 표시한다.

## 진행 기록

- 2026-09-23: parent 작업 트리가 깨끗한 상태에서 sub-feature 브랜치를 생성하고 기록을 시작했다.
- 2026-09-23: 기존 동기 POST를 작업 시작·상태 조회·취소 API로 연결하고, 생성 버튼 옆 취소 동작과 진행 상태를 기존 패널에 표시했다. `cancel_requested` 중에는 재실행을 막고 서버의 최종 상태를 기다린다.
- 2026-09-23: Blog Beta 탭을 떠났다가 돌아올 때 현재 작업을 조회하고, 세션에 남은 작업 ID로 완료 결과도 복원하도록 했다. 토큰으로 오래된 폴링 응답을 무시한다. 취소·실패 시 기존 미리보기를 교체하지 않으며, KIE 이미지 단계의 원격 작업·과금 가능성을 짧게 안내한다.
- 2026-09-23: 브라우저 fixture를 비동기 작업 계약으로 갱신하고, 생성 중 탭 이동·취소 요청 중 중복 차단·기존 미리보기 유지 검사를 추가했다. 집중 검사 91개와 브라우저 smoke가 통과했다. 브라우저 smoke의 첫 반복에서 기존 키워드 모달의 순간 로딩 표시를 기다리는 검사가 시간 초과됐으나 재실행은 통과했다. 변경한 취소 흐름에서 실패한 것은 아니다.
- 2026-09-23: 최종 반복에서 기존 발행 러너 조회가 다른 원고의 발행 중 표시를 덮는 경합이 드러났다. 활성 원고 발행 작업에는 그 조회 결과를 적용하지 않게 막았고, 브라우저 smoke를 다시 통과했다. 저장된 작업 ID가 만료된 경우에도 배경 복구가 불필요한 전역 오류 안내를 띄우지 않도록 처리했다.
- 2026-09-23: UI 모듈 크기 제한 검사에서 `quick-queue.js`가 800줄 한도를 넘은 것을 확인하고 바인딩 구문을 정리했다. 이후 UI 구조·라우트 집중 검사까지 통과했다.
- 2026-09-23: 사용자가 Gemini 텍스트 원고 생성 중 취소가 정상 동작하는 것을 수동 확인했다. 이미지 생성과 KIE 비동기 작업은 추가 수동 확인이 남았다. 같은 확인 과정에서 실패 문구가 하단 두 곳에 중복되고 상단 상세 상태에는 이전 진행 문구가 남는 문제를 발견했다. 수정 범위는 사용자와 논의 중이며 아직 변경하지 않았다.
- 2026-09-24: 사용자가 GPT와 Google의 텍스트·이미지 생성 중 취소, Google의 최종 생성을 확인했다. Anthropic 실제 생성과 KIE 이미지 작업 취소는 parent 통합 확인으로 남긴다. 실패 문구 중복과 상세 상태 불일치는 별도 공통 UX backlog로 분리했다.
- 2026-09-24: 첫 생성 중 취소에도 `기존 원고는 유지됩니다`라고 표시되던 문구를, 이전 미리보기 존재 여부에 맞춰 `이번에 만들던 원고는 저장되지 않았습니다` 또는 `이전에 만든 원고는 유지됩니다`로 나눴다. 문구 위치·화면 구조는 바꾸지 않았다. 실제 원문 AI trace와 로그 노출 정책도 별도 backlog로 기록해 현재 범위에 섞지 않았다.
- 2026-09-24: 사용자의 요청으로 이 브랜치에서 Anthropic Haiku 4.5 연결 확인의 날짜 포함 모델 ID 오류를 별도 commit `4fd1b92`로 수정했다. 생성 취소 UI 변경과는 별개이며, parent 병합 시 함께 포함된다.
- 2026-09-24: 사용자가 Anthropic 생성 중 취소도 확인했다. 사용성 검토 결과 취소 문구는 이전 원고 유무와 관계없이 `원고 생성을 취소했습니다.`로 간결하게 통일하고, KIE 원격 작업 경고만 해당 단계에 유지했다. 발행 설정 유지 문제는 별도 bug backlog에 기록하고 현재 취소 UI 범위에서는 변경하지 않았다.

## 결과와 검증

- 결과: 생성 진행·취소·복귀 UI와 작업 상태 계약을 연결했다. 취소 문구는 원고 저장 상태의 부연 없이 간결하게 표시한다.
- 자동 검증: UI 변경의 기존 관련 집중 검사 95개와 브라우저 smoke 통과. 마지막 문구 변경 후 관련 집중 검사 35개 및 `git diff --check` 통과. 전체 unit suite는 sub-feature→parent 규칙상 실행하지 않았다.
- 수동 확인: GPT·Google 텍스트/이미지 취소와 Anthropic 생성 중 취소, 첫 취소 문구 화면 표시는 사용자가 확인했다. KIE 이미지 제출·폴링 중 취소, 모델 변경 후 재실행, 마지막 유효 원고 보존은 parent 통합 확인에서 점검한다.
- 남은 위험: KIE가 이미 접수한 원격 작업·과금은 로컬 취소 후에도 지속될 수 있다. 중복 오류/오래된 상단 상태와 로그 출력 정책은 `docs/backlog.md`의 별도 후속 항목으로 관리한다.
