# Codex Security 로컬 스캔 시범 적용 기록

- 브랜치: `feature/codex-security-local-scan`
- 시작일: 2026-11-14
- 부모 브랜치: `dev`

## 사용자 요구와 목표

Codex Security CLI를 BlogGenius 저장소의 로컬 코드에 적용해 결과와 비용, 운영 적합성을 확인한다. 블로그 글쓰기 기능 브랜치와 분리해 `dev`를 기준으로 시범 검증하고, 완료된 검증 결과만 사용자 검토 후 통합한다.

## 범위와 비목표

- 로컬 표준 보안 스캔 및 결과 검토.
- 스캔 결과와 비용 추정, 데이터 취급상 주의점 기록.
- 결과물과 리포트는 저장소 바깥의 비공개 경로에 둔다.

비목표:

- Codex Security를 제품 런타임에 통합하거나 의존성으로 추가하지 않는다.
- 자동 패치 적용, 배포, 외부 저장소 게시를 하지 않는다.
- 최초 시범 범위에는 블로그 기능 브랜치의 통합을 포함하지 않았다.

## 설계와 단계

1. 독립된 feature 브랜치를 로컬 `dev`에서 시작하고 진행 기록을 만든다.
2. CLI와 인증 사용 가능 여부를 확인한다.
3. 가능하면 저장소의 격리된 복사본에서 비용 추정 옵션을 설정하고 로컬 스캔한다.
4. 발견을 검토하고 결과 및 후속 권고를 기록한다.
5. 사용자가 요청한 범위에서 테스트 브랜치 결과를 검토하고 통합한다.

## 결정과 트레이드오프

- AI 기반 코드 분석은 기존 `npm audit` 의존성 검사를 보완하는 별도 점검으로 다룬다.
- 스캔에 소스 일부와 취약점 정보가 전송·저장될 수 있으므로 리포트는 비공개 경로에 보관한다.
- `--max-cost`는 추정 모델 비용 기준의 중단 옵션이며 청구액의 확정 상한으로 간주하지 않는다.
- 작업 중이던 블로그 feature 브랜치는 별도로 커밋하고 유지하며 이 시범 브랜치에 포함하지 않는다.

## 진행과 차단 사항

- 2026-11-14: CLI는 전역 설치되지 않았으나, 네트워크 승인 후 `npx @openai/codex-security@latest`로 버전 `0.10.0`을 사용할 수 있었다. 저장된 ChatGPT 로그인은 `authenticated: true`로 확인됐다.
- 실제 로컬 작업 폴더에는 Git에서 무시되는 `.env`와 `.secrets` 파일이 있다. 이를 제외하기 위해 `git archive dev`로 추적 파일만 `/private/tmp/codex-security-local-scan-20261114/source`에 추출했고, 결과 디렉터리를 저장소 밖에 준비했다.
- 원본 저장소 경로와 추적 파일 복사본 각각의 `scan --dry-run`은 통과했다. dry-run은 모델 접근을 검증하지 않는다.
- 추적 파일 전체를 OpenAI 모델 분석 서비스로 보내는 실제 스캔은 자동 승인 검토에서 차단됐다. 검토 사유: 사용자가 도구를 시험해 보도록 승인했지만 소스 페이로드 외부 전송은 별도 명시 승인이 없고, 추정 비용 5달러 옵션은 실제 청구 한도가 아니다. 이 차단을 우회하지 않았다.
- 모델 기반 스캔은 실행되지 않았고 사용량/비용도 발생하지 않았다. 원본 저장소의 코드, 의존성, GitHub Actions는 변경하지 않았다.

## 결과, 검증 및 후속 작업

- 현재 결과: 스캔 미실행. 보안 발견 사항이나 비용 추정 결과는 없다.
- 코드 테스트는 이 문서 외 변경이 없어 수행하지 않았다.
- 후속: 사용자가 추적된 `dev` 소스 파일을 OpenAI 분석 서비스에 전송하는 것과 추정 비용 상한이 실제 청구 상한이 아님을 확인하면, 이 브랜치에서 시범 스캔을 재개한다. 스캔이 끝나면 실제 결과, 비용 정보, 제외 범위, 남은 위험을 여기에 기록한다.
- 수동 UI 확인 대상은 없다.
- 2026-11-20: 사용자가 이 브랜치와 글 구성 브랜치의 `dev` 통합을 요청했다. 스캔 후속 작업은 이 기록에 남긴다.

## 블로그 Beta 외부 참고 수정

- 글 생성과 자동 실행이 동일한 참고 글 검색 어댑터를 쓰도록 연결했다. 회귀 검증에서 모의 검색 결과가 원고 프롬프트에 들어가는지 확인했고, 구조 계약도 공유 연결을 검사하도록 갱신했다.
- 통합 후보의 검증 결과는 글 구성 개발 기록에 정리했다. 실제 앱에서 외부 참고 사용을 켜고 글을 생성하는 수동 확인이 남아 있다.
