## 목표

설정 화면에서 사용자가 현재 설정을 이해하는 데 필요한 기존 Help 가이드로 자연스럽게 이동할 수 있게 한다.

## 범위

- 일반 설정: Google Sheets 연결 및 자동 업데이트 가이드
- AI 설정: AI 모델·API Key 가이드
- 블로그 설정: 네이버 로그인 및 WordPress 연결 가이드
- 글쓰기 설정: 빠른 글 작성 가이드
- Help 콘텐츠와 동일한 URL을 재사용하고 이동 후 해당 카드를 강조

## 비범위

- AI·플랫폼 설정 동작 변경
- Help 콘텐츠 자체의 주소·문구 변경
- SNS·알림 설정의 전용 가이드 추가
- 버전 변경, push, 배포

## 구현 및 검증

- 설정별 contextual Help 버튼과 공통 Help 이동 함수를 구현했다.
- focused Help/UI 구조 테스트를 추가한다.
- 브라우저 smoke에서 설정 → Help 이동과 대상 강조를 확인한다.
- 최종 시각 확인은 사용자가 수행한다.
