# v0.4.3 Release Preparation Development Record

## Branch

## User Need
Prepare the completed v0.4.3 Card News feature for release on a dedicated release branch after the feature parent has been merged into `dev`.

## Goal
Create the `release/v0.4.3` branch from `dev` and align version metadata, user-facing release notes, and release-readiness documentation so the build can be reviewed before any tag, push, package, or publication step.

## Scope
- Merge the completed Card News parent branch into `dev`.
- Create `release/v0.4.3` from the updated `dev`.
- Bump the app version metadata to `0.4.3-dev1` for the first development checkpoint.
- Add concise user-facing `CHANGELOG.md` notes for v0.4.3.
- Run release-appropriate verification after metadata and notes are prepared.

## Explicit Non-goals
- No tag, push, packaging, installer build, or production publication in this step.
- No unrelated feature work or UI polish.
- No automatic publication or production service mutation.

## Release Content
v0.4.3 is centered on Card News:
- source selection from connected blog feeds, custom RSS, direct URL, and pasted content
- AI-assisted card composition, prompt review, local image replacement, and AI image generation
- local ZIP export and ZIP import
- Google Sheet `cardnews` management ledger
- Google Drive-backed public media transport for Card News and SNS local images
- multi-image SNS selection, preview, ordering, and Buffer publication
- supported Electron 44 desktop runtime, with macOS 13+ on Apple Silicon and Windows x64 as the only release targets

## Verification Plan
- Check version consistency between `package.json` and `package-lock.json`.
- Check release-note formatting and Git diff.
- Run release-appropriate automated tests before handoff.
