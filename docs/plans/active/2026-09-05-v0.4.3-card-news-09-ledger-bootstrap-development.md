## User Need

Users need a durable, editable Card News management ledger that can receive RSS candidates, distinguish unmade from made or published work, and later support filtering, scheduled delivery, and channel-link history without storing generated assets in spreadsheet cells.

## Goal

Introduce the smallest safe `cardnews` Google Spreadsheet tab contract and readiness flow. The app should create the tab when missing, repair missing canonical headers without deleting user data, and apply supported workflow and publishing-status dropdowns.

## Scope

- Define the Card News sheet name, headers, and allowed status values in an independent schema module.
- Extend common Spreadsheet readiness to prepare `cardnews` without blocking unrelated app features on failure.
- Add a strict Card News readiness entry point for later ledger operations.
- Create and repair the tab using the established Google Sheets API patterns.
- Add focused automated tests for schema, creation, repair, validation, and isolated failure behavior.

## Explicit Non-goals

- No RSS collection, candidate ingestion, deduplication, or generation-to-ledger synchronization yet.
- No user-facing management UI or filters yet.
- No scheduling or automatic publishing.
- No storage of card images, prompts, local paths, or detailed manifests in Sheets.
- No remote changes to a user spreadsheet during automated tests.

## Design

- The tab name is `cardnews`.
- One future ledger row will represent one source item; this stage creates only the table contract.
- Initial headers are: `entry_key`, `상태`, `발행 상태`, `원문 플랫폼`, `글 제목`, `원문 URL`, `RSS GUID`, `RSS 발행일시`, `수집일시`, `generation_id`, `카드 수`, `발행 채널`, `게시물 링크`, `예약일시`, `처리일시`, `마지막 오류`.
- `상태` and `발행 상태` have separate dropdowns so a completed card set can remain unpublished.
- Existing user columns are preserved. Missing canonical headers are appended; no columns are moved, removed, or overwritten.
- Like `SNS`, common startup attempts readiness with failure isolation. A later Card News operation uses the strict readiness entry point and reports a focused error.
