# v0.4.1 블로그 정식화 개발 기록

## Branch

- Branch: `codex/feature/v0.4.1-blog-productization`
- Base branch: `dev`
- Start date: 2026-09-02
- Status: 진행 중

## 사용자 필요와 목표

v0.4.0에서 도입한 블로그 Beta를 다음 정식 블로그 경험으로 발전시킨다. 기존 블로그의 유용한 기능을 새 구조로 이전하고, 대시보드를 새 발행 흐름과 연결한 뒤, 검증이 끝난 기존 블로그 메뉴는 삭제하지 않고 숨긴다.

## 범위

1. 기존 네이버 스마트 댓글 기능을 새 블로그 구조에 맞게 재설계하고 이전한다.
2. 대시보드를 블로그 Beta의 글감·연속 발행 흐름과 연동해 개선한다.
3. 기존 블로그 메뉴를 숨기고 블로그 Beta를 정식 블로그 메뉴로 전환한다.

## 명시적 비범위

- 네이버 댓글을 사용자의 확인 없이 자동 등록하는 기능
- 기존 블로그 구현의 즉시 삭제
- v0.4.1과 무관한 provider, memory, agent 구조 변경
- 릴리스 버전 변경, 태그, 패키징 및 배포

## 설계 및 단계

각 단계는 독립 검토 가능한 sub-feature branch에서 진행한다.

1. `codex/feature/v0.4.1-smart-comment-integration`
   - 스마트 댓글 UX 재설계 및 새 블로그 통합
   - 기록: [2026-09-02-v0.4.1-smart-comment-integration-development.md](../archive/2026-09-02-v0.4.1-smart-comment-integration-development.md)
2. Dashboard upgrade sub-feature
   - 연결 상태 복원: `codex/feature/v0.4.1-dashboard-connection-readiness`
   - 기록: [2026-09-02-v0.4.1-dashboard-connection-readiness-development.md](../archive/2026-09-02-v0.4.1-dashboard-connection-readiness-development.md)
   - 이후 블로그 Beta 연동과 정보 구조 고도화 범위를 사용자와 다시 확정
3. Blog promotion sub-feature
   - 새 블로그 정식화와 기존 메뉴 hidden 처리

## 사용자와 결정한 사항

- 스마트 댓글을 v0.4.1의 첫 작업으로 진행한다.
- 전체 v0.4.1을 parent feature로 두고, 스마트 댓글은 첫 sub-feature로 격리한다.
- 기존 스마트 댓글 UI를 그대로 복제하지 않고 새 블로그의 시각 체계와 상태 표현에 맞게 다시 설계한다.

## 진행 및 변경 기록

- 2026-09-02: `dev`에서 parent feature branch를 시작했다.
- 2026-09-02: 스마트 댓글을 첫 sub-feature로 결정했다.
- 2026-09-02: 스마트 댓글 sub-feature의 구현, 자동 검증, 사용자 UI 확인을 완료했다. 세 톤 비교와 글 단위 행동으로 최종 UX를 정리했다.
- 2026-09-02: development 실행 중 노출된 Node `DEP0040` 경고의 원인을 기존 `@supabase/supabase-js@2.39.0` 하위의 `@supabase/node-fetch -> whatwg-url -> tr46` 경로로 확인했다. Node 24 조건과 호환되는 `2.113.0`으로 업데이트해 해당 경로를 제거했고, 전체 단위 테스트 1,248개를 통과했다.
- 2026-09-02: `npm audit --omit=dev`에서 기존 production 의존성 경로의 취약점 21건이 보고되었지만 Supabase 패키지는 영향 경로에 포함되지 않았다. 별도 보안 의존성 정비 범위이므로 자동 `audit fix`나 강제 major update는 수행하지 않았다.
- 2026-09-02: 앱 재시작 뒤 네이버와 WordPress가 모두 `확인 필요`로 돌아가는 문제를 Dashboard upgrade의 첫 sub-feature로 분리했다.
- 2026-09-02: 연결 상태 복원 sub-feature의 구현과 자동 검증을 완료했다. 저장된 인증 정보는 재시작 후 자동으로 병렬 검증되며, 사용자 실제 앱 재시작 확인을 기다린다.
- 2026-09-02: 사용자가 앱 재시작 후 설정 화면을 거치지 않아도 네이버와 WordPress가 모두 `확인됨`으로 표시되는 것을 확인했다.
