# BlogGenius 텔레그램 연결 가이드: Bot과 연결 코드로 알림 받기

BlogGenius에서 자동 발행이나 예약 작업을 실행해 두면, 작업이 끝났는지 매번 앱을 열어 확인하기 번거롭습니다. Telegram을 연결하면 자동 작업의 결과를 개인 텔레그램 대화로 받아볼 수 있습니다.

설정 화면에는 Bot Token 입력란과 연결 코드가 보입니다. 이 글에서는 버튼을 누르는 순서뿐 아니라 Telegram 봇이 무엇인지, 연결 코드가 어떤 역할을 하는지, 메시지가 어떤 경로로 도착하는지도 함께 설명합니다.

## 먼저 이해할 세 가지

### Telegram Bot은 자동화용 계정입니다

Telegram Bot은 사람처럼 Telegram 앱에 로그인해 사용하는 계정이 아니라, 프로그램이 Telegram과 메시지를 주고받도록 만든 봇 계정입니다. BotFather에서 봇을 만들면 Bot Token을 발급받습니다. BlogGenius는 이 토큰으로 Telegram Bot API에 요청해 봇을 확인하고 메시지를 보냅니다.

Bot Token은 봇을 제어할 수 있는 비밀 자격 증명입니다. 비밀번호처럼 다루고 다른 사람에게 보내거나 공개된 문서·화면에 노출하지 마세요. BlogGenius는 토큰을 입력란에 다시 보여 주지 않으며, 이미 등록된 토큰을 바꿀 때만 새 값을 입력하도록 안내합니다.

### Chat ID는 메시지를 받을 대화의 주소입니다

봇이 메시지를 보내려면 어느 Telegram 대화로 보낼지 알아야 합니다. Telegram은 대화를 식별하는 숫자형 Chat ID를 사용합니다. 사용자 입장에서는 이 값을 직접 찾아 복사하기 어렵고, Bot Token과 달리 봇을 실행하는 데에도 목적이 다릅니다.

BlogGenius는 Chat ID를 직접 입력하게 하지 않습니다. 사용자가 본인의 개인 대화에서 연결 절차를 완료하면 Telegram이 보내온 대화 정보를 확인해 Chat ID를 내부에 저장합니다. 따라서 사용자는 Bot Token과 연결 코드만 다루면 됩니다.

### 연결 코드는 대화 소유를 확인합니다

봇에 `/start`를 보냈다는 사실만으로 곧바로 알림 수신처를 등록하면, 의도하지 않은 대화가 연결될 수 있습니다. BlogGenius는 일회성 연결 절차를 한 단계 더 둡니다.

1. BlogGenius가 확인한 봇으로 바로 이동하는 개인 대화 링크를 만듭니다.
2. 사용자가 그 링크를 열고 Telegram에서 **시작(Start)**을 누릅니다.
3. 봇이 그 대화로 짧은 연결 코드를 보냅니다.
4. 사용자가 코드를 BlogGenius에 입력해야 해당 대화를 연결합니다.

이 코드는 연결 요청을 시작한 사람과 Telegram 대화가 같은 사람의 흐름 안에 있는지 확인하는 임시 증표입니다. 5분이 지나면 만료되므로 새 연결을 시작해야 합니다.

## 메시지는 어떤 경로로 오갈까요?

연결 과정에는 BlogGenius와 Telegram 사이에 서로 반대 방향의 메시지가 있습니다. 연결 코드 발급과 확인은 연결을 안전하게 마치는 절차이고, 이후 알림은 BlogGenius가 사용자에게 보내는 별도의 메시지입니다.

```text
사용자                 BlogGenius                    Telegram
  │                         │                            │
  │ Bot Token 확인          │ ── 봇 정보 확인 ─────────> │
  │                         │ <── 봇 이름·계정 정보 ───── │
  │ Telegram 열기           │                            │
  │ ───────────────────────────────────────────────────> │ 봇 개인 대화
  │                         │                            │
  │ 시작(Start) 누르기      │ <──── /start + 임시값 ───── │
  │                         │ ───── 8자리 코드 ─────────> │
  │ <─────────────────────────────────────────────────── │
  │ 코드 입력·연결 확인     │                            │
  │ ──────────────────────> │ 대화 확인 후 Chat ID 저장  │
  │                         │ ───── 테스트 메시지 ──────> │
  │ <─────────────────────────────────────────────────── │
```

여기서 **Bot Token은 봇을 확인하고 메시지를 보낼 권한**, **Chat ID는 메시지를 받을 대화**, **연결 코드는 그 대화가 사용자의 것인지 확인하는 임시 수단**입니다. 세 값은 역할이 서로 다릅니다.

## 설정하기

### 1. BlogGenius에서 Bot Token 확인

BlogGenius의 **설정 → 부가 서비스 → 메시지·알림**으로 이동해 Telegram 카드를 엽니다. BotFather에서 발급받은 Bot Token을 입력하고 **Bot Token 확인**을 누릅니다.

확인이 끝나면 BlogGenius가 토큰에 연결된 봇 이름을 표시합니다. 표시된 봇이 연결하려는 봇인지 확인한 뒤 다음 단계로 진행하세요. 토큰이 잘못되었거나 봇 정보를 확인할 수 없으면 연결을 시작할 수 없습니다.

### 2. Telegram에서 봇 대화 시작

**Telegram 열기**를 누르면 확인된 봇의 개인 대화가 열립니다. 봇이 낯선 사용자에게 먼저 메시지를 보낼 수는 없기 때문에, 사용자가 직접 대화를 열고 **시작(Start)**을 눌러야 합니다.

Start는 봇과 대화를 시작하겠다는 Telegram 측 동작입니다. 누르면 BlogGenius가 시작한 임시 연결 요청과 함께 메시지가 봇에 전달되고, 봇은 같은 개인 대화로 8자리 연결 코드를 답합니다.

<!-- 스크린샷: Telegram 개인 대화의 시작 버튼과 봇이 보낸 연결 코드 -->

### 3. 코드를 BlogGenius에 입력

Telegram 메시지에 표시된 8자리 코드를 BlogGenius의 **연결 코드 입력**란에 입력하고 **연결 확인**을 누릅니다. 코드는 대소문자를 구분하지 않습니다. 유효 시간은 5분이며, 틀린 코드 입력은 최대 5회까지 허용됩니다. 요청이 만료되거나 입력 횟수를 초과하면 Telegram 연결을 다시 시작해 새 코드를 받아야 합니다.

확인이 성공하면 BlogGenius가 Telegram 대화의 Chat ID를 내부에 저장하고 테스트 메시지를 보냅니다. Telegram에 테스트 메시지가 도착하면 연결이 완료된 것입니다. 연결은 저장됐지만 테스트 메시지를 보내지 못했다는 안내가 나오면 연결 자체와 메시지 전송 결과를 나누어 확인하세요. 이 경우 Bot Token, Telegram 대화 상태, 연결된 봇을 확인하고 테스트를 다시 진행합니다.

## 연결 후 알림 켜기

Bot 연결과 알림 사용은 같은 설정이 아닙니다. Bot Token과 Chat ID를 저장하면 BlogGenius가 보낼 대상을 알게 되지만, **Telegram 알림 사용**을 켜야 알림을 보냅니다. 설정 카드의 알림 사용 스위치를 켜고 저장 상태를 확인하세요.

알림 설정은 자동·예약 작업의 결과를 전달하기 위한 것입니다. 알림은 각 작업 흐름에서 지원하는 결과에 한해 전송되며, 예를 들어 블로그 자동 발행의 실행 요약, 연속 발행의 완료·확인 필요 결과, SNS 자동 공유의 최종 실패를 안내할 수 있습니다. 작업 종류에 따라 알림 내용이 다를 수 있습니다.

또한 Telegram 명령 수신은 별도 기능입니다. 알림만 받고 싶다면 명령 수신을 켤 필요가 없습니다. 명령 수신을 켜면 BlogGenius가 연결된 대화의 Telegram 명령을 받을 수 있으므로, 필요한 경우에만 별도로 활성화하세요.

## 연결에 문제가 있을 때

### Telegram에서 봇 대화가 열렸지만 코드가 오지 않아요

올바른 봇인지 확인하고 대화에서 **시작(Start)**을 눌렀는지 확인하세요. 브라우저나 Telegram이 이미 열린 대화를 보여 주더라도 Start를 직접 눌러야 연결 절차가 진행됩니다. 연결 요청이 5분 이상 지났다면 BlogGenius에서 연결을 다시 시작하세요.

### 코드를 입력했는데 만료되었다고 나와요

연결 코드는 보안을 위해 5분 후 만료됩니다. 기존 코드를 재사용할 수 없으므로 새 연결을 시작하고 새 코드를 입력하세요.

### 연결은 완료됐지만 테스트 메시지가 오지 않아요

연결 저장과 테스트 메시지 전송은 서로 다른 단계입니다. 연결 상태가 완료로 표시되었는데 테스트 메시지가 오지 않으면 Telegram에서 연결한 봇과 대화가 열려 있는지, 봇을 차단하지 않았는지 확인하고 연결 절차를 다시 진행해 보세요. 알림 수신을 원한다면 Telegram 알림 사용 스위치도 켜져 있는지 확인합니다.

### webhook 사용 중이라는 안내가 나와요

Telegram 봇은 업데이트를 가져오는 polling 방식과 Telegram이 지정한 주소로 전달하는 webhook 방식을 함께 사용할 수 없습니다. 다른 서비스가 해당 봇의 webhook을 설정해 두었다면 BlogGenius가 연결 절차를 시작할 수 없습니다. 그 서비스를 먼저 확인한 뒤 다시 시도하세요.

## 정리

Telegram 설정은 Chat ID를 직접 찾아 입력하는 대신, Bot Token으로 봇을 확인하고 개인 대화에서 받은 일회성 코드를 입력해 대화를 연결합니다. Telegram은 연결된 대화의 Chat ID를 BlogGenius에 전달하고, BlogGenius는 이를 내부에 저장해 자동 작업 알림을 보냅니다.

따라서 사용자가 기억할 것은 간단합니다. **봇을 확인하고, Telegram에서 Start를 누르고, 받은 코드를 BlogGenius에 입력한 뒤, 필요한 알림을 사용 설정하세요.**
