# Cloudflare Workers 기본 연결과 도메인 연결, 무엇이 다른가요?

BlogGenius에서 사이트를 배포하면 Cloudflare Workers의 기본 주소로 사이트를 먼저 공개할 수 있습니다. 여기에 내 도메인을 연결하면 더 익숙하고 기억하기 쉬운 주소로 방문자를 안내할 수 있습니다.

두 연결은 서로 다른 사이트를 만드는 기능이 아닙니다. **같은 사이트를 두 가지 주소로 열 수 있도록 설정하는 과정**입니다.

## 먼저 알아둘 용어

- **Cloudflare 계정**: Cloudflare 서비스와 도메인, Workers를 관리하는 계정입니다.
- **도메인**: `example.com`처럼 소유하고 사용하는 인터넷 주소입니다.
- **호스트 이름**: 도메인 앞에 붙는 이름입니다. 예를 들어 `blog.example.com`에서 `blog`가 호스트 이름입니다.
- **Worker**: Cloudflare에서 사이트 요청을 처리하고 사이트 파일을 방문자에게 전달하는 프로그램입니다.
- **DNS**: 도메인 주소를 실제 서비스와 연결하는 인터넷 주소록입니다.

## 기본 연결: 먼저 확인할 수 있는 Cloudflare 주소

기본 연결은 Cloudflare가 제공하는 `workers.dev` 주소로 사이트를 공개하는 것입니다.

예를 들어 기본 주소가 다음과 같을 수 있습니다.

```text
my-site.my-account.workers.dev
```

BlogGenius에서 처음 배포할 때 이 주소를 사용하면 별도의 도메인을 준비하지 않아도 사이트가 정상적으로 배포됐는지 확인할 수 있습니다.

기본 연결은 다음과 같은 경우에 유용합니다.

- 사이트를 처음 배포하고 결과를 확인할 때
- 도메인을 아직 준비하지 않았을 때
- 커스텀 도메인을 연결하기 전에 사이트를 시험할 때

`workers.dev` 주소는 공개 주소입니다. 주소를 아는 사람은 사이트에 접속할 수 있으므로, 공개하면 안 되는 내용을 올리지 않도록 주의하세요.

## 도메인 연결: 내가 가진 주소로 사이트 열기

도메인 연결은 내가 소유하고 Cloudflare에서 관리하는 도메인을 사이트에 연결하는 것입니다.

예를 들어 `example.com` 도메인을 Cloudflare에서 관리하고 있다면 다음과 같은 주소를 사용할 수 있습니다.

```text
blog.example.com
```

도메인을 연결하면 방문자가 `workers.dev` 주소 대신 이 주소로 사이트에 접속할 수 있습니다.

BlogGenius에서 사이트를 배포한 뒤, 연결할 Cloudflare 도메인과 호스트 이름을 지정합니다. 예를 들어 `example.com`을 고르고 호스트 이름으로 `blog`를 입력하면 `blog.example.com`을 연결하는 방식입니다.

Cloudflare는 커스텀 도메인을 Worker에 연결하면서 필요한 DNS 레코드와 TLS 인증서를 설정합니다. 인증서와 DNS 설정이 준비되는 동안 도메인이 바로 열리지 않을 수 있습니다.

## 왜 기본 연결과 도메인 연결을 구분하나요?

두 연결은 목적과 준비 조건이 다릅니다.

| 구분 | 기본 연결 | 도메인 연결 |
| --- | --- | --- |
| 주소 예시 | `my-site.my-account.workers.dev` | `blog.example.com` |
| 주소 제공자 | Cloudflare | 사용자가 소유한 도메인 |
| 도메인 준비 | 별도 도메인 없이 사용 가능 | Cloudflare에서 활성화된 도메인 필요 |
| 주된 용도 | 첫 배포 확인, 테스트 | 방문자에게 안내할 대표 주소 |
| 설정 시점 | 사이트 배포 시 | 기본 사이트 배포 후 선택적으로 설정 |

기본 연결은 사이트를 빠르게 공개하고 배포 결과를 확인하기 위한 출발점입니다. 도메인 연결은 사이트에 나만의 주소를 부여하는 추가 설정입니다.

## 연결 전에 준비할 사항

### 1. Cloudflare 계정 연결

BlogGenius 설정에서 Cloudflare를 연결해야 합니다. 여러 Cloudflare 계정에 접근할 수 있다면 해당 사이트를 배포하고 관리할 계정을 선택하세요.

도메인도 같은 계정에서 관리할 수 있어야 합니다. 다른 계정에 있는 도메인은 현재 연결된 계정의 도메인 목록에 나타나지 않을 수 있습니다.

### 2. 도메인을 Cloudflare에서 활성화

사용할 도메인이 아직 Cloudflare에 등록되어 있지 않다면 Cloudflare에 도메인을 추가하고 안내에 따라 설정해야 합니다.

도메인을 구입한 업체와 Cloudflare는 서로 다른 역할을 합니다. 도메인 등록 업체를 바꾸지 않고도 Cloudflare를 DNS 관리에 사용할 수 있습니다. 다만 Cloudflare가 안내하는 네임서버 변경이 필요한 경우, 도메인 등록 업체의 관리 화면에서 변경해야 합니다.

네임서버를 바꾸기 전에는 기존 DNS 설정을 확인하세요. 웹사이트나 이메일에 필요한 레코드가 있다면 설정이 유지되도록 살펴보는 것이 좋습니다.

### 3. 사용할 주소 결정

`example.com`과 `www.example.com`은 서로 다른 호스트 이름입니다. `blog.example.com`도 별도의 주소입니다.

사용할 주소를 미리 정하고, 필요한 주소를 각각 연결하세요. 한 주소를 연결했다고 해서 `www`가 붙거나 빠진 주소까지 자동으로 연결되지는 않습니다. 두 주소를 모두 운영하고 싶다면 각각 연결하거나, 한 주소에서 다른 주소로 이동하도록 별도의 리디렉션을 설정해야 합니다.

## 권장하는 연결 순서

1. BlogGenius 설정에서 Cloudflare를 연결합니다.
2. 사이트를 Cloudflare에 배포합니다.
3. 기본 `workers.dev` 주소를 열어 사이트가 잘 표시되는지 확인합니다.
4. 필요하면 사이트 카드에서 도메인 연결을 시작합니다.
5. Cloudflare 계정과 도메인을 선택하고 연결할 호스트 이름을 지정합니다.
6. 도메인 주소로 접속해 사이트가 열리는지 확인합니다.

기본 주소에서 사이트가 정상적으로 열리는 것을 먼저 확인하면, 문제가 생겼을 때 사이트 배포와 도메인 설정 중 어느 쪽을 살펴봐야 하는지 구분하기 쉽습니다.

## 이미 DNS 레코드가 있다면 확인하세요

연결하려는 호스트 이름에 기존 DNS 레코드가 있으면 연결이 실패할 수 있습니다. 예를 들어 `blog.example.com`에 이미 다른 서비스의 CNAME 레코드가 설정되어 있다면 충돌 여부를 확인해야 합니다.

기존 레코드를 변경하기 전에 그 주소가 현재 어떤 서비스에 사용되는지 확인하세요. 레코드를 잘못 바꾸면 기존 웹사이트나 이메일 서비스에 영향을 줄 수 있습니다.

## 문제가 생겼을 때 확인할 항목

### 기본 주소에서 사이트가 열리지 않아요

- BlogGenius에서 Cloudflare가 연결되어 있는지 확인합니다.
- 사이트 배포가 완료됐는지 확인합니다.
- 배포 화면에 표시된 기본 주소가 맞는지 확인합니다.
- 배포 직후라면 잠시 기다린 뒤 다시 확인합니다.

### 도메인 연결에 실패해요

- 도메인이 Cloudflare에서 활성 상태인지 확인합니다.
- BlogGenius에 연결한 계정에서 해당 도메인을 관리할 수 있는지 확인합니다.
- 연결할 호스트 이름에 충돌하는 DNS 레코드가 있는지 확인합니다.
- 입력한 호스트 이름이 원하는 주소와 일치하는지 확인합니다. 예를 들어 `blog`를 입력하면 `blog.example.com`을 연결하게 됩니다.
- 인증서와 DNS 설정이 준비될 때까지 잠시 기다린 뒤 다시 확인합니다.

### `example.com`은 열리는데 `www.example.com`은 열리지 않아요

두 주소는 별개의 호스트 이름입니다. 원하는 주소를 추가로 연결하거나, 한 주소를 다른 주소로 보내는 리디렉션을 설정해야 합니다.

## Cloudflare 연결을 해제하면 어떻게 되나요?

BlogGenius의 Cloudflare 연결 해제는 BlogGenius가 Cloudflare에 접근할 권한을 해제하는 작업입니다. 이미 배포된 사이트의 주소와 파일을 삭제하는 작업과는 다릅니다.

사이트 자체를 삭제하거나 기본 Worker 연결을 해제하는 작업은 별도의 결과를 낳을 수 있습니다. 특히 커스텀 도메인이 연결된 사이트는 도메인 연결을 먼저 해제해야 기본 Worker를 정리할 수 있습니다. 버튼의 안내를 확인한 뒤 진행하세요.

## 자주 묻는 질문

### 도메인이 없어도 사이트를 배포할 수 있나요?

네. Cloudflare 기본 `workers.dev` 주소로 배포하고 확인할 수 있습니다. 원하는 경우 나중에 도메인을 연결하면 됩니다.

### 도메인을 연결하면 기본 주소는 없어지나요?

아닙니다. 기본 주소와 커스텀 도메인은 같은 사이트를 여는 주소로 함께 사용할 수 있습니다.

### 커스텀 도메인을 연결하면 사이트를 다시 만들어야 하나요?

아닙니다. 도메인은 이미 배포된 Worker에 연결합니다. 별도의 사이트 복사본을 만드는 과정이 아닙니다.

### Cloudflare에 도메인을 등록하려면 도메인 업체도 바꿔야 하나요?

일반적으로 도메인 등록 업체를 바꿀 필요는 없습니다. 다만 Cloudflare에서 DNS를 관리하려면 Cloudflare에 도메인을 추가하고, 안내에 따라 네임서버를 설정해야 할 수 있습니다.

### 도메인을 연결했는데 바로 접속되지 않아요

DNS 설정이나 TLS 인증서가 준비되는 데 시간이 걸릴 수 있습니다. 잠시 기다린 뒤 다시 확인하고, 계속 문제가 있으면 Cloudflare의 도메인 상태와 DNS 레코드를 점검하세요.
