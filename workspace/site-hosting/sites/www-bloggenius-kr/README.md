# BlogGenius 사이트 ZIP

Astro 기반 정적 사이트입니다. 사이트 정보와 메뉴는 `site-data/site.json`에서 읽습니다. BlogGenius의 사이트 호스팅에서 이 프로젝트 ZIP을 가져와 사이트로 준비할 수 있습니다.

## 로컬 미리보기 및 빌드

```sh
npm ci
npm run dev
npm run build
```

빌드 산출물은 `dist/`에 생성됩니다. 다운로드 버튼은 GitHub Releases의 다음 파일 이름을 사용합니다.

- macOS Apple Silicon: `BlogGenius-mac-arm64.zip`
- Windows x64: `BlogGenius-win-x64.exe`

정책 페이지의 운영자 표시, 시행일, 처리 항목, 보관·삭제 기준, 유료 플랜과 환불 안내가 실제 운영과 일치하는지 공개 전에 확인해 주세요.
