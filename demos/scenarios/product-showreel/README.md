# BlogGenius Product Showreel

짧은 브라우저 시연 영상으로 대시보드, AI 설정, 스타일 전환, 트렌드 조회, 업데이트 확인까지 빠르게 보여줍니다.

## 실행

1. 개발 환경의 BlogGenius UI 서버를 실행합니다.
2. Playwright로 녹화합니다.

```sh
UI_BROWSER_HEADLESS=true node scripts/create-live-product-showreel.js
```

기본 접속 주소는 `http://127.0.0.1:4577`이며, `BLOGGENIUS_DEMO_URL`로 바꿀 수 있습니다. 결과는 이 폴더의 `product-showreel.webm`입니다.

## 장면

- 대시보드 스크롤과 사이드바 접기/펼치기
- 저장된 글쓰기 모델과 연결 상태
- 여러 화면에서 스타일 전환
- 개발 트렌드 데이터 조회
- 강제 업데이트 확인 알림

스타일 전환은 새 브라우저 세션 안에서만 수행합니다. 모델 연결 상태와 트렌드 데이터는 실제 개발 환경에서 읽습니다. 새 AI 연결 테스트는 호출하지 않습니다. 업데이트 확인은 실제로 수행하지만, 설치 및 재시작은 시작하지 않습니다. 개발 체크아웃에 업데이트를 설치하면 현재 작업 파일에 영향을 줄 수 있기 때문입니다.
