# BlogGenius desktop teaser

## 목적

A-to-Z overview와 분리된, 실제 BlogGenius Prod 데스크톱 앱의 핵심 순간만 담는 짧은 티저다.
설명 자막, 별도 내레이션, 편집용 아웃트로를 넣지 않는다. 앱 화면과 실제 동작을 순수 캡처하고,
후편집은 별도 단계에서 한다.

## 촬영 시나리오

목표 길이는 약 35–55초이며, 로딩이 필요한 장면은 결과가 자연스럽게 드러날 만큼만 보여준다.

1. **즉각적인 스타일 변경** — 설정에서 스타일을 선택하고 대시보드 또는 블로그 화면으로 돌아와 전체 분위기가 바로 바뀐 것을 짧게 보여준다.
2. **블록 에디터 편집과 이미지 생성** — 직접 입력으로 짧은 원고를 열고 문장을 다듬는다. 이미지 블록을 추가해 장면·스타일을 요청하고 실제 AI 이미지를 생성한 뒤, 결과를 확인한다.
3. **네이버 블로그 headed 임시 저장** — 발행 설정에서 네이버와 `임시 저장`을 선택하고 브라우저 표시 실행을 켠다. 네이버 편집 화면에서 원고와 이미지를 쓰고 임시 저장하는 과정을 담는다.
4. **완료 축하 효과** — 앱으로 돌아와 임시 저장 완료 상태와 앱의 축하 애니메이션을 보여준다. 이 장면은 별도 제작 그래픽이 아닌 제품 UI를 캡처한다.
5. **셀프 업데이트** — 앱 업데이트에서 강제 확인을 실행하고, 확인 대화상자에서 선택된 최신 버전 재설치를 시작한다. 다운로드·검증·설치와 앱 재시작 후 업데이트 완료 효과까지 연속 캡처한다.

흐름은 `스타일 변화 → 글과 이미지 제작 → 네이버 임시 저장 → 완료 피드백 → 자체 업데이트`로 이어진다.

## 촬영 전 준비

- BlogGenius Prod가 실행 가능하고, 유효한 라이선스와 AI 설정이 준비되어 있어야 한다.
- 네이버 headed 실행에서 사용할 계정을 앱의 브라우저 세션에 직접 로그인한다. 촬영 대상은 공개 발행이 아닌 전용 테스트 블로그를 권장한다.
- 네이버 임시 저장은 외부 서비스에 실제 콘텐츠를 전송하고 테스트 블로그에 남긴다. 촬영에 쓸 원고는 공개해도 문제가 없는 내용으로 준비한다.
- 실제 AI 원고·이미지 생성을 사용하므로 호출 비용이 발생할 수 있다.
- 강제 업데이트 확인은 현재 설치 버전보다 높은 버전만 찾는 동작이 아니다. 현재 코드상 선택된 채널의 최신 버전을 확인하며, 강제 모드에서는 같은 버전이어도 해당 플랫폼 패키지가 있으면 재설치를 제안할 수 있다. macOS Apple Silicon용 최신 에셋이 선택된 채널에 게시되어 있는지 먼저 확인한다.
- 업데이트는 앱 파일을 교체하고 앱을 재시작한다. 화면 녹화는 앱 재시작을 포함해 계속 캡처할 수 있도록 준비한다.
- macOS가 화면 기록 권한을 요청하면 녹화 앱에 권한을 허용한다. 계정 비밀번호나 개인 정보는 녹화 화면에 노출하지 않는다.

## 캡처 원칙과 범위

- 브라우저 fixture, 데모 데이터 주입, 합성 AI 결과를 사용하지 않는다. 실제 설치된 Prod 데스크톱 앱의 화면을 캡처한다.
- 화면 조작은 데스크톱 UI 자동화를 사용하고, 녹화는 macOS 화면 녹화로 별도 수행한다.
- Naver는 테스트 블로그에 임시 저장만 한다. 공개 발행, 예약 발행, 실사용 블로그 수정은 시나리오에 포함하지 않는다.
- 강제 업데이트는 확인된 최신 채널 패키지를 재설치한다. 업데이트 채널이나 배포물을 바꾸지는 않는다.
- 축하 효과는 실제 임시 저장 완료 시점의 앱 반응을 촬영한다. 최종 아웃트로·브랜드 그래픽·자막은 넣지 않는다.
- 촬영 후 임시 저장 콘텐츠의 보존/정리는 사용자가 확인한다. 본 영상에 별도 편집을 할 경우 원본 캡처도 보관한다.

## 구현 상태

현재는 촬영 계획 문서다. 실제 Prod 앱 조작 및 녹화는 계정 준비와 촬영 시작 지시를 받은 뒤 별도 수행한다.

## 확인한 구현 근거

- 강제 업데이트 확인 및 최신 버전 재설치 안내: `ui/partials/views/settings-next.html`, `ui/scripts/shell/update.js`
- 같은 버전에서도 강제 업데이트가 가능한 버전 비교 분기: `src/updater.js`
- 업데이트 재시작 후 완료 축하 표시: `ui/scripts/shell/celebration.js`
- 네이버 임시 저장/브라우저 표시 실행 설정: `ui/scripts/features/blog/draft-inputs.js`, `ui/scripts/features/blog/runner.js`
- 블록 에디터 이미지 작업: `ui/scripts/features/blog/draft-images.js`
