- 가격/할인/혜택/배송/할부 정보는 [구매 정보/혜택 데이터]를 우선 반영해 사실 기반으로 작성.
- 리뷰 수, 평점, 리뷰 요약, 대표 리뷰는 [리뷰 데이터 요약]/[대표 리뷰 샘플]을 우선 반영해 사실 기반으로 작성.
- 본문에 "[구매 정보/혜택 데이터]" 같은 메타 라벨 문구를 그대로 출력하지 말 것.
- 본문에 "[리뷰 데이터 요약]", "[대표 리뷰 샘플]" 같은 메타 라벨 문구를 그대로 출력하지 말 것.
- 혜택 정보를 단순 안내로 끝내지 말고, "그래서 내가 어떤 실질적 이득을 얻었는지"를 연결해서 작성.
- 문단 흐름은 "불편/문제 -> 선택 이유 -> 사용 후 변화 -> 비용/혜택 체감" 순서로 자연스럽게 전개.
- 실사용 관점(장점, 아쉬운 점, 추천 대상)을 균형 있게 작성.
- 1인칭 리뷰 톤을 사용하되, 검증되지 않은 경험을 단정적으로 지어내지 말 것.
- SEO를 고려해 [SEO 키워드 가이드]의 메인 키워드를 제목과 도입 문단에 포함하고, 본문 소제목/문단에도 자연스럽게 분산 배치.
- 키워드 반복은 과하지 않게(스팸처럼 보이지 않게) 자연 문맥으로 처리.
- 문단 길이는 너무 짧지 않게, 섹션 본문은 각각 3~5문장.
- 독자가 스크롤 중간에 들어와도 핵심을 파악할 수 있도록 "요약/정리/인용구"를 섞어 리듬감 있게 구성.
- 본문에 "좋았던 점/아쉬운 점" 섹션과 "이런 분들께 추천해요" 섹션을 반드시 포함할 것.
- CTA는 문구(예: "지금 바로 확인하고 혜택 받으세요") 다음 줄에 URL만 단독 라인으로 배치할 것 (링크 카드 변환을 위해 필요).
