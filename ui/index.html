알림 설정

          

            
텔레그램

            

              
              자동 발행 완료 시 텔레그램으로 알림을 보냅니다. 체크박스 변경은 저장 전까지는 설정 초안이며, `저장 및 적용` 시 실제 봇 상태에 반영됩니다.
            


            

              
텔레그램 적용 상태

              

            


            

            

            

            

              
              
            


            

              
텔레그램 채팅 모델

              텔레그램 자연어 해석에 사용할 모델을 선택하세요. 글 작성용 메인 모델에는 영향을 주지 않습니다.
            


            
          


          

            
Slack

            

              
              자동 발행 완료 시 Slack으로 알림을 보냅니다. (Incoming Webhook URL이 필요합니다)
            


            
          


          

            
            
          

        


        

          
AI 설정

          

            

              
Custom AI

              Custom AI는 글 작성용 메인 모델이 아니라, 텔레그램 같은 가벼운 채팅/보조 해석 작업에 사용하는 OpenAI-compatible 모델입니다.
            


            

            

            

            

              
              
            


            
MCP 설정

            

              Remote MCP Server
              
              
                같은 컴퓨터, 동일 네트워크, reverse proxy 공개 시나리오를 위한 별도 MCP endpoint 설정입니다.
