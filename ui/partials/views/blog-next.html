새 흐름 준비 중

글감을 빠르게 쌓아두고, 준비된 글을 한 건씩 이어서 발행하는 새로운 흐름입니다.

기존 블로그 기능은 그대로 유지됩니다. 이 화면은 새로운 연속 발행 흐름을 단계적으로 검증하는 공간입니다.

빠른 글 작성

입력 방식을 고른 뒤 글감만 저장하거나, 발행 계획을 완성해 대기열에 추가합니다.

바로 생성

주제, 키워드와 지시사항을 등록하고 글감별 발행 대상과 실행 방식을 확정합니다.

글감 입력→발행 계획 확인→대기열 추가

원고 폴더

Markdown과 이미지가 담긴 로컬 폴더를 사용합니다. Queue 편입 전 파일 지속성과 실행 PC 소유권을 먼저 검증합니다.

원고 붙여넣기

완성된 Markdown 원고를 붙여넣어 바로 발행하거나 안전하게 보관하는 흐름을 준비합니다.
