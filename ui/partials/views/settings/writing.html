글쓰기 프로필

한 번 저장하면 일반 블로그와 쇼핑 글 생성 전체에 적용됩니다. 글별 지시사항은 해당 글에서만 우선합니다.

불러오기 전 글쓰기 탭을 열면 프로필을 불러옵니다.

공통 글쓰기 성향

블로그와 쇼핑에 함께 적용되는 문장 표현입니다.

블로그 글 구성

일반 블로그 본문의 길이, 흐름, 화자와 이미지 영역을 정합니다.

이미지 생성 기능을 꺼도 원고의 이미지 영역과 프롬프트는 유지됩니다. 글별 이미지 개수를 지정하면 이 설정보다 우선합니다.

블로그 참고 문체

문장이나 공개 HTTPS 블로그를 분석해 원문을 복제하지 않는 문체 특징으로 저장합니다.

자료 없음
분석된 fingerprint만 실제 블로그 생성에 적용됩니다.

쇼핑 글 구성

상품 사실성, 출력 구조, FTC·CTA·상품 이미지 정책은 제품 기본값으로 보호됩니다.
